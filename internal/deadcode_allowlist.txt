# deadcode_allowlist.txt -- exemptions for the unreachable-symbol guard
# (internal/deadcode_test.go, run by `just deadcode-check`).
#
# `deadcode -test=false ./...` lists every function unreachable from the
# shipped binary's call graph. This file is the only thing that may keep a
# listed symbol out of a CI failure. An entry with no class or no reason is a
# defect the guard itself rejects (R8); an entry naming a symbol that is no
# longer in the current unreachable output -- deleted, renamed, or made
# reachable -- is stale and also rejected (R11).
#
# Format: one entry per line, four "|"-delimited fields:
#   <package import path>|<Symbol or Receiver.Method>|<class>|<reason>
#
# Classes (KTD3 -- no other value is accepted):
#   reflection-dispatched   -- called only via encoding/xml, encoding/json,
#                               yaml.v3, or fmt's %v/%s (Stringer); deadcode's
#                               static RTA call graph cannot see the call.
#   test-time-safety-gate   -- code whose whole job is to be run against
#                               generated output by a test (e.g. a redaction
#                               or markdown-validity assertion helper).
#   public-surface          -- deliberately-retained public API, out of scope
#                               for this sweep by Key Decision (session-settled:
#                               the pkg/schema public surface is snapshot-locked
#                               by d20d8535 and the dynamic plugin loader is a
#                               deliberate open-core seam).
#
# Do NOT add an entry here because "nothing calls it any more" inside
# internal/ or cmd/ -- delete the function instead. This file exists to
# exempt code that is unreachable BY DESIGN, not to launder dead code back
# into a passing build. See docs/plans/2026-09-08-2250-refactor-dead-surface-
# cleanup-plan.md and GOTCHAS.md.
